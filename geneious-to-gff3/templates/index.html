Turn annotated Geneious sequences into GFF3 gene models

Upload a sequence annotated with exon and, for a coding transcript, CDS; say where it sits on the chromosome; download a checked GFF3 file with Unix line endings. Exons without a CDS become a non-coding transcript such as a lncRNA. Splice variants join the same gene, and finished genes can be merged into one file for the curator.
